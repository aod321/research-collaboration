# Retired

Rules that were promoted and later withdrawn, kept with their original incident
so that "tried and withdrawn" stays searchable rather than becoming a gap.

Format:

```
**<rule name>** — promoted YYYY-MM-DD, retired YYYY-MM-DD
Original incident: <verbatim quote>
Why retired: <the evidence, usually accumulated conflict tickets>
Superseded by: <the sharper rule, if any>
```
